# かんたん家計簿

PythonとTkinterで作った、ダッシュボード付きのデスクトップ家計簿アプリです。

ダークテーマ、OSに合わせた見やすいフォント、大きなボタン、カテゴリ別の色分けを
採用しています。入力データはローカルに保存され、外部サービスには送信されません。

<img src="assets/app_icon.png" alt="かんたん家計簿のアプリアイコン" width="160">

## できること

- ホーム画面で今月の支出・予算・残り予算を確認する
- 一番支出が多いカテゴリと前月比を確認する
- ホーム画面で円グラフと棒グラフを確認する
- 「予算を設定」から月ごとの予算を保存する
- 支出を追加する
- すべての支出を見る
- 月ごと・カテゴリごとの合計を見る
- 月ごとの支出を棒グラフで見る
- 指定した月のカテゴリ別支出を円グラフで見る
- 間違えた支出を削除する
- 入力内容を `kakeibo.csv` に保存する
- これらの操作をマウスとキーボードで行う

## 必要環境

- Python 3.10以降
- Tkinter（通常のPythonには同梱されています）
- macOSまたはWindows

実行時に外部ライブラリは必要ありません。

## セットアップと起動

リポジトリを取得して、プロジェクトへ移動します。

```bash
git clone https://github.com/fearless0712/kakeibo-app.git
cd kakeibo-app
```

ウィンドウ版アプリを起動します。

```bash
python3 gui_app.py
```

日付・カテゴリ・金額・メモを入力して「追加する」をクリックしてください。
一覧の行をクリックしてから「選択した行を削除」を押すと削除できます。
「グラフを表示」をクリックすると、月別の棒グラフとカテゴリ別の円グラフが
別ウィンドウで開きます。円グラフには「表示する月」で指定した月が使われます。

以前のターミナル版も、次のコマンドで引き続き使えます。

```bash
python3 app.py
```

## プロジェクト構成

- `gui_app.py`: ウィンドウと画面操作
- `app.py`: CSVの読み書きと、以前のターミナル版
- `assets/app_icon.png`: Macアプリ用のアイコン元画像
- `kakeibo.spec`: PyInstallerのビルド設定
- `scripts/build_macos.sh`: Macアプリのビルドスクリプト
- `requirements-build.txt`: ビルド時だけ必要なライブラリ
- `kakeibo.csv`: 入力したデータ（初回起動時に自動作成）
- `budgets.json`: 月ごとの予算（予算設定時に自動作成）

## 初心者向けコードの読み方

`gui_app.py` は、上から次の順番で作られています。

1. `tkinter` を読み込む
2. `KakeiboApp` クラスでウィンドウ全体を定義する
3. `create_widgets()` で入力欄・ボタン・表を並べる
4. `add_record()` などでボタンを押したときの動作を定義する
5. `main()` でウィンドウを表示する

関数とは、処理をひとまとまりにして名前を付けたものです。たとえば
`add_record()` は「支出を追加する処理」をまとめています。クラスは、画面の部品と
その動作をひとまとめにするための仕組みです。

## CSVを直接見る

`kakeibo.csv` はExcelや表計算ソフトでも開けます。ただし、アプリを動かしている
最中には編集しないでください。

## Macアプリをビルドする

PyInstallerを使うと、Finderからダブルクリックで起動できる
`かんたん家計簿.app` を作成できます。ビルド作業はmacOS上で行ってください。

### 1. ビルド用の仮想環境を作る

ターミナルでプロジェクトへ移動し、仮想環境を作成します。

```bash
cd kakeibo-app
python3 -m venv .venv
source .venv/bin/activate
```

### 2. PyInstallerをインストールする

```bash
python3 -m pip install --upgrade pip
python3 -m pip install -r requirements-build.txt
```

`Pillow` も一緒にインストールされます。これは高解像度の
`assets/app_icon.png` をMacアプリ用アイコンへ変換するために使われます。

### 3. アプリをビルドする

```bash
./scripts/build_macos.sh
```

完了すると、次のアプリが作成されます。

```text
dist/かんたん家計簿.app
```

Finderで `dist` フォルダを開き、`かんたん家計簿.app` をダブルクリックすると
起動できます。`Applications` フォルダへドラッグして使うこともできます。

### 配布する

アプリを右クリックして「圧縮」を選び、作成されたZIPファイルを配布します。
署名していない個人制作アプリのため、別のMacで初めて開くときは、アプリを
Controlキーを押しながらクリックして「開く」を選ぶ必要がある場合があります。

配布版で入力した家計簿と予算は、次のフォルダへ保存されます。

```text
~/Library/Application Support/Kakeibo/
```

アプリを更新しても、このフォルダのデータは維持されます。
